The classical representation of a neuron is misleading. What is generally represented as synapses that let action potential into the neuron are actually the *proximal synapses* which lie near the neuron body and only account for 10% of the cells synapses. The other 90% lie far away from the neuron (called *distal synapses*) and when an input arrives at one of these synapses, it has almost no effect on the cell body. 

![[Distal Synapses.jpeg]]

On distal synapses, the synapses are tightly packed in each dendritic branch (see box above); when a group pf twenty or so synapses situated next to each other on a dendrite branch receive input at the same time, the spike travels along the dendrite to the cell body, where it raises the voltage of the cell, but not enough to make a neuron spike. These spikes act as predictions. A dendrite spike basically means that the neuron has recognised a pattern of activity in some other neurons. When this happens, it raises the voltage of the cell body, putting it in a predictive state. It's as if it's primed. If subsequently the cell gets enough proximal input to create an action potential spike, then the cell spikes a little bit sooner that it would if it had not been primed. 

In each [[How the Brain is Structured#^bbf291|minicolumn]], multiple neurons respond to the same input pattern. If their preferred input arrives, they all want to start spiking. However, if one or more of the neurons are in the predictive state, only those neurons spike and others are inhibited. Thus when an unexpected input arrives, multiple neurons fire, while when the input is predicted, only the primed neurons are active. This is a common observation about the neocortex - unexpected inputs cause more activity than expected ones. 

With thousands of distal synapses, each neuron can recognise hundreds of patterns that predict when the neuron should become active. Now with several thousand neurons arranged in minicolumns and connected to each other, and in the presence of some inhibitory neurons, we have a systemt hat can learn sequences without getting confused by even repeated sub-sequences.
